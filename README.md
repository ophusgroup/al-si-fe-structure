# Al-Si-Fe intermetallic structure report

Structure determination of an Al-Si-Fe intermetallic particle from
multi-zone-axis atomic resolution STEM. The particle is the tetragonal
tau4 (delta) phase Al3FeSi2 with ferroelastic {112} twin domains.

Built with [MyST Markdown](https://mystmd.org/).

## Build

```
myst build --html
python3 scripts/patch_theme.py   # flat top-bar search (no dialog)
myst build --html                # rebuild with the patched theme
```

or for local preview, `myst start` and run the patch script once the
theme has been downloaded into `_build/templates`.

## Figures

All data figures are generated by `scripts/make_figures.py`, which reads
the microscope data from the path set at the top of the script and writes
PNGs plus a JSON fit table into `assets/figures/`. Run it with any python
that has numpy, h5py, and matplotlib.
