# ZA2: [130] domain A

| | |
| --- | --- |
| Goniometer | $\alpha = 18.98°$, $\beta = -1.26°$ |
| Domain, zone axis | domain A, $[130]$ |
| Measured cell | 1.911 × 4.780 Å, 90.1° |
| Model cell | 1.917 × 4.763 Å, 90.0° |
| Fitted blur, correlation | $\sigma = 0.65$ Å, $r = 0.99$ |

The $[130]$ projection compresses the structure into a narrow 1.92 Å repeat ($a/\sqrt{10}$) transverse to the beam, with the familiar $c/2$ period along the other axis. At this spacing the individual columns are not resolved and the image reduces to modulated fringes. The simulation reproduces the fringe profile at $r = 0.99$.

This dataset shows the strongest diffuse half-order intensity along $c^*$ of the whole series, the signature of the (001) antiphase boundaries discussed on the [structure page](../structure/model.md).
