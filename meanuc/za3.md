# ZA3: [010] domain A

| | |
| --- | --- |
| Goniometer | $\alpha = 37.15°$, $\beta = -0.22°$ |
| Domain, zone axis | domain A, $[010]$ |
| Measured cell | 3.031 × 4.767 Å, 90.2° |
| Model cell | 3.031 × 4.763 Å, 90.0° |
| Fitted blur, correlation | $\sigma = 0.65$ Å, $r = 0.98$ |

Along $[010]$ the Fe columns form a rectangular $a/2 \times c/2$ net. The projected Bravais lattice of $I4/mcm$ along this direction is centred, but the Fe column decoration completes the finer rectangular net, and the image shows the finer periodicity.

Two data notes. First, the registered image in the ZA3 folder is the same field of view as ZA5_1, so this page and the [ZA5 page](za5.md) are two independent averages of the same orientation; their cells agree to 0.1 percent. Second, the raw scans in the ZA3 folder were recorded at a different tilt, $\alpha = 10.94°$, $\beta = -2.20°$, which the parent orientation fit identifies as the $[120]$ zone. Those scans have not yet been drift corrected and are the one unprocessed orientation in the dataset. Third, the original lattice fit for this dataset used a cell doubled along $u$; the mean cell shown here is folded back to the primitive repeat.
