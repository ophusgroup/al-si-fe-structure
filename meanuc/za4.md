# ZA4: [210] domain A

| | |
| --- | --- |
| Goniometer | $\alpha = -25.66°$, $\beta = -4.87°$ |
| Domain, zone axis | domain A, $[210]$ |
| Measured cell | 2.705 × 9.540 Å, 89.7° |
| Model cell | 2.711 × 9.525 Å, 89.9° |
| Fitted blur, correlation | $\sigma = 0.55$ Å, $r = 0.97$ |

The $[210]$ projection is the only parent orientation that shows the full $c = 9.5$ Å repeat rather than $c/2$, because the projected cell is centred: the column at the cell center sits at $c/2$ with a half transverse offset. The parity analysis of the mean cell confirms the centring translation to high accuracy, exactly as the $I4/mcm$ model requires.

This is the most decoration-sensitive projection in the series: it resolves the staggered Al/Si column pairs between the Fe rows, and it is the projection that discriminates hardest between candidate structures. Placing Fe on the $4c$ site instead of $4a$, for example, drops the correlation from 0.97 to 0.63. The simulation reproduces the experimental dot pattern in detail.
