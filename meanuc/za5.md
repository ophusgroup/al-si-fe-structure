# ZA5: [010] domain A

| | |
| --- | --- |
| Goniometer | $\alpha = 37.15°$, $\beta = -0.22°$ |
| Domain, zone axis | domain A, $[010]$ |
| Measured cell | 3.028 × 4.769 Å, 89.9° |
| Model cell | 3.031 × 4.763 Å, 90.0° |
| Fitted blur, correlation | $\sigma = 0.75$ Å, $r = 0.98$ |

Second, independent average of the $[010]$ orientation, from a different region of the same field of view as [ZA3](za3.md). The measured cells agree to 0.1 percent and the two mean cells match the same simulation, a direct check on the reproducibility of the averaging pipeline.
