# ZA1: [110] domain A

| | |
| --- | --- |
| Goniometer | $\alpha = -7.08°$, $\beta = -2.91°$ |
| Domain, zone axis | domain A, $[110]$ |
| Measured cell | 4.281 × 4.767 Å, 89.9° |
| Model cell | 4.286 × 4.763 Å, 90.0° |
| Fitted blur, correlation | $\sigma = 0.55$ Å, $r = 0.95$ |

Along $[110]$ the Fe columns form a rectangular net of $a/\sqrt{2} \times c/2$, and the Al/Si columns fill the space between them. Several mixed columns fall close together in projection and merge into the elongated bright features between the Fe columns.

The correlation of 0.95 is the lowest of the domain A datasets, consistent with the averaging region including faulted material; this image also shows the strongest planar-fault contrast in the series.
