# ZA7: [33-1] domain B

| | |
| --- | --- |
| Goniometer | $\alpha = 24.70°$, $\beta = -7.97°$ |
| Domain, zone axis | domain B, $[33\bar{1}]$ |
| Measured cell | 2.949 × 8.671 Å, 89.9° |
| Model cell | 2.976 × 8.574 Å, 89.9° |
| Fitted blur, correlation | $\sigma = 0.70$ Å, $r = 1.00$ |

First of the three domain B orientations. The simulation reproduces the characteristic wavy bright rows at $r = 0.996$, the best match in the series. The projected cell is centred, with the 8.67 Å repeat along the domain B $[1\bar{1}0]$ axis, the direction shared by all three twin zones. The measured repeat runs one percent above the ideal $a\sqrt{2} = 8.57$ Å, which we read as strain in domain B.

The recorded goniometer values for this dataset were recovered from the microscope metadata; the folder name lists them as unknown. The original lattice fit used a cell doubled along $u$, folded back here. The mirror-related twin zone $[331]$ is shown on the [ZA9 page](za9.md), and the two mean cells agree to 0.3 percent.
